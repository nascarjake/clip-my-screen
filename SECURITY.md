# Security

Please report vulnerabilities privately through [GitHub's vulnerability reporting](https://github.com/nascarjake/clip-my-screen/security/advisories/new). Include the affected version, platform, a small reproduction, and impact. Avoid uploading personal recordings or live share tokens.

This is early-release desktop software. Install only from this repository's releases or build the source yourself. Mac downloads are ad-hoc signed and unnotarized; Windows downloads are unsigned. Release checksums detect an unexpected download change; they do not provide a trusted publisher identity.

Saved captures stay local until you choose to share them. Anyone with a share link can view that capture while the originating app is reachable. Revoke links you no longer need and use public tunnels only when you intend internet access. Screen-recording and microphone authorization remain controlled by the operating system.
